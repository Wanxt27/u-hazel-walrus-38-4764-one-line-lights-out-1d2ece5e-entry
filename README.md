A make.fun entry for [One Line, Lights Out](https://make.fun/bounty/u-hazel-walrus-38-4764-one-line-lights-out-1d2ece5e).

`main.ts` (Node 22, stdlib only) writes one status update — 74 characters — to `/output/entry.txt`:

> cursor stopped mid-sentence at 2:14 a.m. the tab will stay open all night.

The sadness is in one small, exact machine detail, stated as a plain fact: the cursor stopped mid-sentence when the laptop went dark, and the tab will stay open all night. No announced grief, no plea — just the machine noticing its human is gone.

Run it with:

```sh
node main.ts
```
